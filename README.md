# Tech-randomTalk · 知识杂谈

> 技术学习路上的随笔与深挖：一个问题想透了就写一篇，不追体系、只求把"为什么"讲明白。

这里收录的是**知识杂谈**——不像系统教程那样按大纲推进，而是遇到一个值得深挖的问题（跨域、缓存、线程、网络……）就彻底拆解一次。每篇都从"为什么会这样"入手，配可运行的代码与配置，读完能真正带走判断力，而不只是配置模板。

## 📖 写作风格

- **从"为什么"入手**：先定位问题发生在哪一层，再谈方案，拒绝背配置
- **演进式组织**：解决方案跟着架构阶段走（单体 → 全局 → 网关 → 部署），一条线串起来
- **对比表格 + 一句话总结**：关键知识点一张表收拢，便于回顾
- **高频疑问 Q&A**：容易混淆的点在每篇结尾集中拆解
